# Garden design workbook

`screen-catalog.html` is an editable, source-backed design deliverable. Open it in any browser and edit the HTML/CSS or the linked `garden-design-kit.json` in an editor. It documents 37 current product routes and universal states as artboards, 9 reusable wireframe patterns, and the extracted visual kit.

The source of truth remains the implemented UI:

- `src/styles.css` — semantic theme tokens, typography, layout rules;
- `src/components/ui.jsx` — core component variants;
- `src/components/page.jsx`, `catalog.jsx`, `detail-sidebar.jsx` — composition patterns;
- `src/app.jsx` — route inventory.

The workbook intentionally represents data as realistic-but-generic content. It contains no copied user data, credentials, or production records.
