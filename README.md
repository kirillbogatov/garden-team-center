# Garden Team Center

Garden — локальный командный центр для руководителя и команды. Сервис объединяет ежедневную работу, проекты, встречи, командный контекст и рабочие сигналы в одном интерфейсе.

## Возможности

### Обзор
- настраиваемый главный экран с рабочими виджетами;
- сигналы о ближайших событиях и загрузке команды;
- закреплённые записи из журнала;
- персональные и командные рабочие показатели.

### Команда
- карточки сотрудников и стейкхолдеров;
- связанные задачи, проекты, встречи и другой рабочий контекст;
- персональные стикеры в правом сайдбаре;
- перенос стикера в журнал с автоматическим упоминанием сотрудника.

### Задачи

На «Обзоре» виджет **«Мои задачи»** показывает до пяти приоритетных задач текущего пользователя. Для тимлида доступен отдельный виджет **«Задачи команды»** с задачами остальных сотрудников. Оба виджета используют выбранную в настройках стратегию: с равным весом срока и важности, с большим весом срока, важности или просрочки.
- список задач с фильтрами и статусами;
- отдельная страница каждой задачи;
- проекты, исполнители, сроки и приоритеты;
- архивирование и удаление;
- автосохранение изменений.

### Проекты
- список и отдельные страницы проектов;
- участники и связанные рабочие сущности;
- правый сайдбар со стикерами;
- перенос проектного стикера в журнал с упоминанием проекта.

### Процессы
- список процессов с фокусом на проблемных состояниях;
- уникальные идентификаторы `PROCESS-0001`, `PROCESS-0002` и далее;
- статусы: «Работает», «Есть проблемы», «Сломан»;
- описание ожидаемого и фактического поведения процесса;
- несколько вариантов исправления со статусами проверки;
- автосохранение, архивирование и удаление.

### Встречи
- встречи типов 1:1, PR, клаб, ретро, проектные и другие;
- фильтрация списка встреч по типу;
- несколько участников встречи;
- связанные проекты, задачи и follow-up действия;
- отдельная страница созданной встречи.

### Календарь и Check-in
- календарное представление рабочих событий;
- командный Check-in с редактированием непосредственно в таблице;
- просмотр по неделям и сотрудникам.

### Журнал
- единая лента заметок и рабочего контекста;
- упоминания сотрудников и проектов;
- закрепление записей для показа на главной странице;
- ссылки в заметках и связанных текстовых полях.

### The Labs и идеи
- список командных идей;
- идеи могут существовать отдельно или быть связаны с проектами The Labs;
- отдельные страницы проектов The Labs;
- фильтрация идей по сотрудникам и наличию проекта.

### Стикеры
- быстрые заметки в правом сайдбаре проектов и сотрудников;
- изменение порядка перетаскиванием;
- одно- и двухколоночная раскладка;
- базовое форматирование текста и цвет стикера;
- перенос заметки в журнал с сохранением контекста сущности.

## Технологии

- Node.js
- Express
- SQLite
- Vanilla JavaScript / HTML / CSS

## Запуск

Требуется Node.js версии 22.5 или новее.

```bash
npm install
npm start
```

После запуска откройте адрес, который будет указан сервером в терминале.

## Тесты

```bash
npm test
```

Проект также содержит архитектурные и theme-тесты для основных клиентских сценариев и визуальных контрактов.

## Данные

Garden задуман как локальный сервис. Рабочие данные хранятся в локальной базе SQLite. Перед публикацией или переносом проекта не добавляйте файлы рабочей базы и `.env` в репозиторий — они исключены через `.gitignore`.
