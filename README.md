# Garden Team Center

Garden — локальный командный центр для тимлида и команды. Здесь собраны задачи, проекты, встречи, сотрудники, командные сигналы и рабочий контекст.

## Что умеет Garden

### Обзор

Главный экран показывает то, что требует внимания:

- **Мои задачи** — до пяти задач текущего пользователя с учётом срока и важности;
- **Задачи команды** — приоритетные задачи остальных сотрудников для тимлида;
- **Встречи без итогов** — прошедшие встречи без итогов и документов;
- проблемы с загрузкой команды, ближайшие события и записи из журнала.

Стратегию приоритета задач можно выбрать в настройках: сбалансированную, по дедлайнам, по важности или для разгребания долгов.

### Сотрудники

- карточки сотрудников и стейкхолдеров;
- задачи, проекты, встречи, Check-in и другой контекст сотрудника;
- загрузка и рабочий статус;
- стикеры в правой панели;
- перенос стикера в журнал с упоминанием сотрудника.

### Задачи

- список и канбан;
- фильтры по сотруднику, проекту и статусу;
- исполнитель, проект, срок и пометка «Важная»;
- автоподстановка сотрудника и проекта из активных фильтров при создании задачи;
- быстрый выбор срока: сегодня, завтра, конец недели;
- отдельная страница задачи с автосохранением;
- архивирование и удаление.

### Проекты

- список и отдельные страницы проектов;
- участники и связанные задачи;
- стикеры проекта;
- перенос стикера в журнал с упоминанием проекта.

### Процессы

- реестр процессов и проблем;
- идентификаторы `PROCESS-0001`, `PROCESS-0002` и далее;
- статусы «Работает», «Есть проблемы», «Сломан»;
- ожидаемое и фактическое поведение процесса;
- несколько вариантов исправления со статусами проверки;
- автосохранение, архивирование и удаление.

### Встречи

Типы встреч: **1:1**, **PR**, **Клаб**, **Ретро**, **Проектные**, **Другое**.

- вкладки «Будущие», «Завершённые», «Без итогов», «Все»;
- фильтр по типу встречи;
- несколько участников с аватарами;
- связь с проектом;
- итоги встречи, документы и действия по итогам;
- метка «нет записей по итогам» для прошедших встреч без итогов и документов.

### Check-in

- таблица состояния команды;
- просмотр по неделям и сотрудникам;
- редактирование прямо в таблице;
- экспорт за выбранный период по всем или одному сотруднику в XLSX, CSV или Markdown;
- создание задачи или проблемы из записи Check-in.

### Журнал

- заметки и рабочий контекст;
- упоминания сотрудников и проектов;
- ссылки в тексте;
- закреплённые записи для главной страницы.

### The Labs

- идеи и экспериментальные проекты;
- отдельный список идей;
- фильтрация по сотруднику и наличию проекта;
- отдельные страницы проектов The Labs.

### Стикеры

- быстрые заметки в правой панели;
- изменение порядка перетаскиванием;
- одна или две колонки;
- жирный и курсивный текст, цвет стикера;
- перенос в журнал с контекстом сотрудника или проекта.

### История версий

Для задач, встреч и проектов The Labs Garden хранит осмысленные версии вместо снимка после каждого автосохранения:

- изменения в течение 10 минут объединяются в одну версию;
- при уходе со страницы текущая версия фиксируется;
- смена статуса и другие важные изменения сохраняются отдельно;
- в истории кратко указано, что изменилось.

### Поиск

Поиск понимает названия сущностей и разговорные запросы. Например:

- `встречи без итогов 1:1 Дуайта`;
- `просроченные встречи проекта ATOM`;
- `важные задачи Маши`;
- `сломанные процессы`;
- `check-in с блокерами`.

## Технологии

- Node.js 22.5+
- Express
- SQLite
- Vanilla JavaScript, HTML и CSS

## Запуск

```bash
npm ci
npm start
```

После запуска откройте адрес из терминала.

Рабочие данные хранятся вне исходного кода в SQLite. `.env`, база данных, загруженные файлы и `node_modules` исключены через `.gitignore`.

## Тесты

Все тесты:

```bash
npm test
```

Клиентская архитектура, поиск и темы без запуска API-тестов:

```bash
npm run test:client
```

API-тесты:

```bash
npm run test:api
```
